# ArcaneKnockout Funding Media

Public screenshots, gameplay video and Windows prototype for the ArcaneKnockout funding application.

[Open the supporting-materials link collection](SUPPORTING_MATERIALS.md) for the official website, Android and Windows prototypes, gameplay video, screenshots, budget and developer background.

## Proposed funding budget

[Download the editable $30,000 budget spreadsheet](ArcaneKnockout-Funding-Budget-30000-USD.xlsx).
The four-month proposal covers the founder plus two developer hires conditional
on funding, with $18,000 in developer allowances and $12,000 in other costs,
including $3,000 for PR and marketing. The $1,500 per person per month pay rate
and other costs are planning estimates, not confirmed quotations. The milestone
sheet retains the 2027 ship-year target; timing depends on funding, hiring and QA.

## Playable prototype

[Download the Windows x64 prototype (ZIP)](https://github.com/minthukyawdev-droid/ArcaneKnockout-Screenshots/releases/download/funding-prototype-2026-10-15/ArcaneKnockout-Windows-x64-Prototype-2026-10-15.zip).
Extract the entire archive and run `ArcaneKnockout.exe`; no Unity Editor is required.
Use **PLAY → OFFLINE → choose a mode/map → CHOOSE LOADOUT → START MATCH**.
The first launch may start the playable tutorial; it can be followed or skipped.
Keyboard/mouse instructions are included in `README.txt`.

Offline play needs no sign-in or additional players. Live online/Relay play has
not been verified for this desktop package. A macOS build is not included.
[Release details, validation and checksum](https://github.com/minthukyawdev-droid/ArcaneKnockout-Screenshots/releases/tag/funding-prototype-2026-10-15).

## Gameplay video

[Watch the 90-second gameplay video](https://minthukyawdev-droid.github.io/ArcaneKnockout-Screenshots/)
or [download the MP4](ArcaneKnockout-gameplay-90s.mp4).

Actual Unity Editor gameplay with offline bots, captured at 1280×720 / 24 fps.
The silent video contains three 30-second clips, one per Survival arena: Arcane
Citadel, Molten Crucible, and Venom Sanctum. The first participant also uses the
existing bot controller; no human or live multiplayer session is implied.
Between-round upgrades use the normal choice flow. The footage shows actual
combat, HUD, warnings and collapse. A small caption identifies the capture context.
